# Seizure Forecasting and Fatal-Crash Risk

Analysis code and figures for the technical appendix of our paper on seizure
forecasting and driving. The code computes how many days per year a person with
epilepsy could drive, given a seizure forecast, while keeping fatal-crash risk on
permitted driving days at or below a safety threshold. The threshold is 5.66 times
the baseline risk, which corresponds to a blood alcohol concentration of 0.05%
under the Zador doubling rule.

## Reproducing the results

Requires Python 3.11 or later.

```bash
pip install -r requirements.txt
jupyter notebook crashes_vs_TiW.ipynb          # interactive; run all cells
# or, non-interactively (rewrites the notebook outputs and figure files):
jupyter nbconvert --to notebook --execute --inplace crashes_vs_TiW.ipynb
```

The notebook runs in a few seconds and is deterministic (no simulation).

**Tested with** Python 3.14.4, NumPy 2.4.2, SciPy 1.17.1, Matplotlib 3.10.8,
nbconvert 7.17.0, on macOS. The first cell of the notebook prints the versions
in use.

## Method in brief

* Forecast scores are N(0, 1) on non-seizure days. On seizure days they follow one
  of three models, each calibrated in closed form to the target AUC: equal-variance
  binormal, unequal-variance binormal (σ₁ = 1.4), or a two-component mixture
  (w = 0.7).
* Daily seizure probability is p_d = 1 − exp(−R) for a seizure rate of R per day.
* On forecast-safe days the residual seizure probability p_res follows from Bayes'
  rule. The relative fatal-crash risk is RR = 1 + p_res (A − D/24), where
  A = q_f / (24 λ_f), λ_f = 4.4 × 10⁻⁷ fatal-crash involvements per hour of
  driving, and q_f = 0.02.
* The operating threshold is the largest score threshold with RR ≤ T = 2^(0.05/0.02).
  It is found by root-finding (Brent's method) on the exact expressions; no
  threshold grids are used.

The appendix gives full derivations and sources.
